# Giuseppe Arlo C. Provido

Final-year **BS Mechanical Engineering** student at De La Salle University–Dasmariñas, Philippines. I work on **HVAC/R, cooling-load calculation and data-centre cooling** — and I write software when the tool I need does not exist.

**[CoolLoad Studio](https://github.com/Xheir/CoolLoad-Studio)** — a free Windows cooling-load calculator implementing the ASHRAE CLTD/CLF method, built because the commercial program my course requires is discontinued. Validated zone by zone against a real 40-zone building: 1.89 % median deviation, 31 of 39 zones within 5 %, whole-building total within 1.5 %.

What I care about: a number you cannot reproduce is not a result. Every claim in that repository comes with the comparison sheet that produced it.
